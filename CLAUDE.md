# NRTFTree-Async

The facts about this repo for an AI session. The development process is not in this file.

## What it is

NRtfTree with async support. It is a C# library of classes that read and change RTF documents. The original NRtfTree was written by Salvador Gomez.

## Parts

The solution is `NRtfTree-Async.sln`. It has one project, `NRtfTree/NRtfTree-Async.csproj`, a library that targets `net8.0`. A build makes the NuGet package `NRTFTree-Async`.

The repo has no tests. It states no build command.
